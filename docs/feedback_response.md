# 강사 가능시간 DB 설계 피드백 보완 답변

## 1. 테이블정의서 보완

- `backend/docs/table_definition.md`에 `TBL_TUTOR_AVAILABLE_TIME` 테이블정의서를 작성했습니다.
- 테이블 개요, 컬럼명, 데이터 형식, Null 여부, 컬럼 설명, 인덱스, 설계 기준을 정리했습니다.

## 2. MySQL 문자열 타입 수정

- 기존 `01_schema.sql`의 `tutorName` 컬럼은 MySQL 기준에 맞지 않는 Unicode 문자열 타입으로 작성되어 있었습니다.
- MySQL에서는 DB 문자셋을 `utf8mb4`로 설정하면 `VARCHAR`로도 한글 저장이 가능하므로 `VARCHAR(50)`으로 수정했습니다.

## 3. 요일 저장 방식

- 요일은 DB에 `월`, `화`, `수` 같은 문자열로 저장하지 않고 `TINYINT` 숫자로 저장합니다.
- 숫자 기준은 Python `datetime.now().weekday()`와 맞춰 `0=월, 1=화, 2=수, 3=목, 4=금`으로 정리했습니다.
- 숫자로 저장하면 문자열보다 저장 공간이 작고, 정렬과 비교 조건을 처리하기 쉽습니다.

## 4. 백엔드 한글 요일 표시 사유

- FastAPI 응답의 `dayName`은 DB에 저장되는 값이 아닙니다.
- DB에는 `dayOfWeek` 숫자만 저장하고, 백엔드에서 사용자가 이해하기 쉽도록 숫자를 한글 요일명으로 변환해 응답합니다.
- 예를 들어 DB 값이 `0`이면 FastAPI 응답에서는 `dayOfWeek: 0`, `dayName: "월"`로 내려갑니다.

## 5. 확장 기준

- 현재 과제 범위에서는 평일 데이터만 사용하므로 `0~4`까지만 사용합니다.
- 주말 수업 가능시간이 필요해지면 같은 기준으로 `5=토`, `6=일`을 추가할 수 있습니다.
